# 발주서 011 — /preview/ 대상. 본편 전환은 광희님 승인 후.

A. 앞선 추가 판정(미반영분)
1. 베이 수: house 1, lowrise 2, midrise 3(타일 전체). 가운데 베이 복제 제거.
2. house는 타워크레인 없음, 카메라는 건물만 프레임. 1180·390에서 house 화면 세로 비율 측정(목표 1180 35%↑, 390 25%↑).
3. 크레인 클라이밍: 높이 = 현재 진행 최상층 + 1.5층. 층이 오를 때 마스트 1칸 끼워지는 0.6초 연출, 카메라는 층마다 1초 줌아웃(009 규칙 복원). 준공 후 크레인 0.8초에 걸쳐 내려가며 해체.

B. 내 회사의 스카이라인 (신규, 이번 핵심)
4. 준공한 건물은 사라지지 않고 장면 뒤쪽 레이어(skyline-near 앞, 현장 뒤)에 0.6배 크기로 남는다. 위치는 왼쪽부터 빈자리에 배치, 겹침 최소화. 최대 12채 표시, 넘으면 가장 오래된 것부터 빠짐. 밤에는 창문 불빛(기존 마스크).
5. 저장 데이터에 준공 건물 목록(타입·층수·순서)만 추가. core 규칙 변경 없음(표시용 기록). 기존 저장은 completedProjects 수만큼 house로 채워 호환.
6. 준공 순간: 현장 건물이 0.8초에 걸쳐 줄어들며 뒤쪽 자리로 이동하는 연출. 빈 부지는 펜스 공터로 돌아감.

C. 모바일 정리
7. HUD 한 줄: 현금·신뢰도·현장 n/max 칩만. 면허·순자산은 칩 탭 시 펼침. 언어·음소거는 우상단 ⚙ 하나로 묶어 설정 패널로. 390px에서 HUD 높이 56px 이하.
8. 빈 부지·다음 부지 안내를 허공 카드 대신 공터 위 간판(기둥 2개 + 판)으로, 지면에 붙여 그림. 매입 버튼은 간판 안.
9. 타이틀 화면 언어 토글 폭을 버튼 폭에 맞춤(모바일에서 화면 끝까지 늘어나는 문제).

D. 완료
- 테스트 + 튜토리얼 완주 통과, /preview/ 재배포.
- 390px 스크린샷 4장: 주택 공사 중 / 8층 공사 중 3층 시점 / 준공 직후(뒤쪽에 건물 남은 상태) / 준공 6채 이상 쌓인 상태(테스트 저장으로).
- 주소 한 줄과 측정값 보고 후 정지.
