# 발주서 008 — 화면 재구성: 현장이 주인공

규칙·숫자 변경 없음. UI·theme만.

## 1. 레이아웃 뒤집기
- 현장 장면(scene)이 화면 전체 배경. 상단 HUD 칩(현금·신뢰도·면허·현장 n/max) 반투명 오버레이. 입찰 게시판·회사 패널은 하단 탭 바(입찰 / 회사 / 로그)로 서랍처럼 올라옴. 기본은 닫힘, 서랍 열려도 장면 상단 1/3은 보임.
- 동시 현장 1~3개는 한 장면 안에 가로로 나란히(빈 부지는 펜스 쳐진 공터 + "부지 매입" 간판). 현장 클릭/탭 → 그 현장 상세(계약·기성·검사관·펀치·포기)가 장면 아래 카드로 펼쳐짐.
- 데스크톱·모바일 동일 구조. 모바일은 현장 가로 스크롤(스냅).

## 2. 장면 레이어 (뒤→앞), 전부 교체 가능한 슬롯
sky → skyline-far → skyline-near → ground → [현장: foundation, floors×n, roof, crane] → workers/vehicles → weather overlay → HUD
- 각 레이어는 theme.art 슬롯으로 정의. 지금은 벡터/그라데이션으로 채우고, 슬롯에 이미지 경로가 지정되면 그 이미지를 쓴다(009에서 교체). 층 타일은 "같은 폭·높이로 쌓는 타일" 전제로 구현.
- 건물은 현재의 3배 크기. 8층이 화면 세로 70%를 쓰도록 층 높이 산정, 1층 주택은 지면 가까이 작게.

## 3. 생명감 (벡터, 2~3프레임)
- 작업자 3~6명(현장 규모 비례): 지면 좌우 왕복, 골조 중엔 진행 층 위에 2명, 비 오면 전원 가설사무실로 뛰어 들어감, 정체(자금 부족) 땐 앉아서 대기.
- 레미콘 트럭: 타설(foundation·structural 시작) 때 좌→우 진입·정차·후진 후 퇴장.
- 검사관: 검사 시점에 클립보드 들고 걸어 들어와 건물 앞에 서고, 결과 토스트와 함께 ✓ 또는 ✗ 말풍선, 걸어 나감.
- 크레인: 기존 동작 유지, 자재 들어올릴 때 해당 층으로 올라감.
- 시간대: 실시간 4분 주기로 아침→낮→저녁→밤. 하늘색·그림자 방향·창문 불빛(완료 층은 밤에 불 켜짐)·크레인 경광등.
- 전부 transform/opacity, 60fps 유지, motionEnabled로 일괄 차단.

## 4. 피드백 강화
- 기성 입금: 돈이 건물에서 HUD 현금으로 날아가는 코인 궤적 3~5개 + 숫자 카운트업(기존).
- 준공(CO): 건물 전체 플래시, 지붕 위 깃발, 작업자 환호 프레임, 1.5초.
- 검사 실패: 해당 층 빨간 점멸 + 검사관 ✗ 말풍선.
- 펀치: 주황 점이 해당 층 외벽에 붙고(기존), 정리 시 작업자가 그 층으로 올라가 지움.

## 5. 튜토리얼 호환
- 007 스포트라이트 대상(data-guide)은 새 레이아웃에서 전부 유효해야 함. T1~T8 통과 테스트가 그대로 통과.
- 서랍이 닫혀 있을 때 T1(입찰)·T7·T8은 해당 서랍을 자동으로 열고 비춤.
