# 발주서 004 — 비주얼·모션·사운드

게임 규칙 변경 금지(BALANCE 숫자 불변).

## 1. 아트 방향 (확정)
- 벡터(인라인 SVG + CSS). 도트 아님. 이미지 파일 최소화, 외부 에셋 다운로드 없이 코드로 그린다.
- 톤: 건설 현장. 콘크리트 회색 바탕, 안전모 노랑을 유일한 강조색, 청사진 파랑을 수치·정보에. 경고는 주황, 위험은 빨강, 통과는 초록.
- 모든 색·크기는 theme.ts에만. 다른 파일에 색·px 리터럴 0 유지(기존 reviewer 규칙).
- 폰트는 시스템 폰트 스택. 웹폰트 다운로드 금지(로딩 시간).

## 2. 건물 캔버스 재작업 (핵심)
- 현장을 옆에서 본 단면으로. 지면선, 기초, 층, 지붕, 그리고 현장 옆에 타워크레인 1기.
- 타워크레인: 지브가 아주 천천히 회전(20초 1회전), 훅이 미세하게 흔들림. 골조 진행 중에는 자재를 들어올리는 동작 반복, 정지 중에는 멈춤.
- 층 상태별 표현: 미착공(빈 격자선) / 골조 중(철골 라인이 왼쪽부터 차오름) / 골조 검사 대기(점선 테두리 점멸) / 설비 중(층 안에 배관·전선 라인이 그려짐) / 완료(채워진 벽면 + 창문).
- 층 완성 시: 아래에서 위로 200ms 슬라이드 + 살짝 바운스.
- 기초·외장·최종 단계는 건물 하단·외곽·상단에 각각 시각화.
- 펀치: 미정리 minor를 건물 위 주황 점으로 표시(최대 10개 표시 후 "+n"). 정리하면 하나씩 사라짐.

## 3. 상태 연출
- 강우: 캔버스에 빗줄기 애니메이션, 화면 전체 채도 낮춤, 크레인 정지. "Pour anyway" 버튼은 주황 경고색.
- 검사 통과: 해당 부위에 초록 체크 배지가 스케일 팝(300ms) 후 페이드.
- 검사 실패(Major): 카드 좌우 흔들림(shake 400ms) + 빨간 테두리 플래시 + 결함명 토스트.
- Minor 발생: 주황 점이 건물에 톡 붙는 애니메이션.
- 기성 입금: 상단 현금 숫자가 800ms 카운트업 + 현장 카드에서 "+$22,500"이 위로 떠오르며 페이드.
- 자금 부족 정체: 카드 테두리 빨강 점멸(느리게), 부족액 강조.
- 기한 임박(20% 남음): 기한 표시 주황, 초과 시 빨강 점멸.
- 신뢰도·현금 변화는 항상 숫자 트윈. 즉시 점프 금지.
- 모든 애니메이션은 prefers-reduced-motion 존중, theme의 motionEnabled로 일괄 차단 가능.

## 4. RFQ 게시판·회사 패널
- RFQ 카드를 청사진 카드 느낌으로(격자 배경, 모노스페이스 수치). 검사관 성향은 아이콘+색(lenient 초록 / normal 회색 / strict 빨강), 발주처 성향도 아이콘.
- 견적 3버튼에 낙찰 확률을 막대로 시각화. 예상 마진은 색으로(흑자 초록/적자 빨강).
- 새 RFQ 등장은 위에서 슬라이드 인, 거절·낙찰은 슬라이드 아웃.
- 협력업체 5종에 공종 아이콘(안전모·철골·전기·배관·소화기). 레벨은 점 5개가 아니라 게이지.

## 5. 사운드
- Kenney(CC0) 또는 동등한 CC0 사운드팩에서 6종: 클릭, 낙찰, 검사 통과, 검사 실패, 기성 입금, 준공(CO).
- 총 용량 500KB 이하, mp3 또는 ogg. 출처와 라이선스를 docs/ASSETS.md에 기록.
- 기본 음소거 ON, 우측 상단 토글. 설정은 localStorage.
- 사운드팩을 네트워크 제약으로 받지 못하면 받지 말고 보고할 것. 임의로 다른 소스를 쓰지 말 것.

## 6. 첫인상
- 타이틀 화면: 게임명(가칭 "Contractor Tycoon"), Start 버튼, 배경에 크레인 실루엣. 이어하기 저장이 있으면 Continue 우선.
- 첫 로딩에 스켈레톤 표시. 흰 화면 금지.
- 파비콘도 코드 생성(SVG).

## 7. 제약
- core·data·save 수정 금지. UI와 theme만.
- 빌드 20MB 미만, 초기 로딩 10초 미만 유지. 애니메이션은 transform·opacity 위주로(레이아웃 리플로우 유발 금지).
- 저사양에서 60fps 유지 확인. 프레임 드랍 시 애니메이션 자동 감축 로직.
- 모바일 390px에서 전부 동작. 터치 타겟 44px 이상.
