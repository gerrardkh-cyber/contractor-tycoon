# 발주서 007 — 안내 튜토리얼(첫 공사 1채)

규칙·숫자 변경 없음. UI만.

## 1. 원칙
- 튜토리얼 = 첫 house 1채를 준공할 때까지의 안내 흐름. 별도 모드가 아니라 실제 게임 위에 오버레이.
- 한 번에 지시 하나. 지시한 버튼만 활성, 나머지 버튼은 비활성 + 흐리게. 화면 전체 어둡게 하고 대상 요소만 밝게(스포트라이트).
- 지시 문구는 한 줄, 그 아래 "왜"를 한 줄. 두 줄 넘기지 않음. 전부 strings 파일(en/ko 1:1).
- 플레이어 행동으로만 다음 단계로 넘어감. "다음" 버튼 없음.
- 게임 이벤트가 처음 일어날 때 그 자리에서 설명(검사 결과, 기성 입금, 비). 사전 설명 금지.
- 우측 상단 "안내 건너뛰기" 상시 노출. 건너뛰면 모든 패널 즉시 해제.
- 완료 여부 localStorage 저장. 완료·건너뛴 뒤에는 다시 안 뜸. Settings에서 "안내 다시 보기" 가능.

## 2. 단계 (첫 house, 지명 입찰)
각 단계: 스포트라이트 대상 → 지시 한 줄 → 이유 한 줄 → 진행 조건.

T1 입찰 게시판의 지명 카드만 보임(다른 2칸·슬롯 카드·회사 패널 숨김).
   "이 공사를 수주하세요." / "발주처가 당신을 지명했습니다. 경쟁 없이 바로 계약합니다." → 수주 클릭.
T2 현장 카드 등장. 진행 바 스포트라이트.
   "기초 공사가 시작됐습니다." / "공사비는 착수할 때 빠지고, 돈은 검사에 합격해야 들어옵니다." → 상단 현금이 줄어드는 순간 현금 숫자로 스포트라이트 이동(1.5초), 자동 진행.
T3 첫 검사 결과 토스트 발생 시 토스트 스포트라이트.
   합격: "검사 합격. 기성이 들어왔습니다." / "유보금 10%는 준공 때 한꺼번에 받습니다."
   불합격: "검사 불합격. 재시공합니다." / "시간과 돈이 더 듭니다. 협력업체를 키우면 합격률이 오릅니다." → 토스트 사라지면 자동 진행.
T4 비 이벤트가 첫 공사 중 발생하면 선택 버튼 스포트라이트.
   "비가 와서 타설이 멈췄습니다." / "기다리면 안전하고, 강행하면 빠르지만 검사가 어려워집니다." → 선택 시 진행. 발생 안 하면 생략.
T5 minor 펀치 첫 발생 시 펀치 버튼 스포트라이트.
   "검사관이 지적 사항을 남겼습니다." / "준공 전에 전부 정리해야 합니다. 지금 정리하세요." → 정리 클릭.
T6 CO 달성 시 현장 카드 전체 스포트라이트 + 유보금 입금 연출.
   "준공! 유보금까지 전액 받았습니다." / "이제 입찰로 다음 공사를 따냅니다." → 2초 후 진행.
T7 게시판 전체 해제. 일반 카드의 견적 3버튼 스포트라이트.
   "견적을 고르세요." / "싸게 내면 잘 따지만 남는 게 적고, 비싸게 내면 반대입니다." → 아무 입찰 클릭.
T8 회사 패널 해제. 협력업체 영역 스포트라이트.
   "돈이 모이면 협력업체를 키우세요." / "공사가 빨라지고 검사 합격률이 오릅니다." → 3초 후 해제. 튜토리얼 종료, 완료 저장.

## 3. 숨김 규칙
- T1~T6 동안: 슬롯 카드(빈 부지·다음 부지) 숨김, 회사 패널 숨김, 이벤트 로그 접힘 고정, 게시판 지명 카드 외 숨김.
- 상단 바는 항상 보이되 T2 전까지 현금 외 항목은 흐리게.
- 튜토리얼 중 지명 카드의 기한은 넉넉히(기존 1.5배 → 3배). 튜토리얼 끝나면 원래대로. core 변경이 아니라 첫 RFQ 생성 파라미터로 처리 가능하면 그렇게, 불가하면 보고.

## 4. 용어 툴팁(튜토리얼 이후에도 유지)
- 기성·유보금·선수금·펀치·검사관·발주처 성향·면허 라벨에 ⓘ 아이콘. 탭/호버 시 한 줄 설명. 모바일은 탭으로 열고 바깥 탭으로 닫힘.

## 5. 첫 화면 정리(튜토리얼과 별개, 영구)
- 입찰 카드의 성향·검사관 배지에 색 외에 짧은 텍스트 설명을 호버/탭 툴팁으로.
- "필요 현금" 배지를 "입찰 자격 $57,375" 로 바꾸고, 미달 시 "부족 $x" 를 같은 줄에.

## 6. 완료 조건
- 저장 삭제 후 새로 시작 → T1~T8이 순서대로 동작하는 스크린샷 각 1장(T4는 발생 시에만).
- 건너뛰기 동작, 재시작 시 미노출, Settings 재보기 확인.
- 모바일 390px에서 스포트라이트·툴팁 동작 스크린샷 1장.
- reviewer·테스트 통과, 배포(main 푸시 → Pages 자동 배포)까지 완료하고 공개 주소에서 새로 시작 시 T1이 뜨는지 확인 후 정지.
