# 발주서 005 — 첫 30초 수정

규칙 구조 변경 없음.

1. 시작 자본 $80,000 → $95,000. (house min_cash $57,375 + 첫 structural 여유)
2. RFQ 게시판 다양성: 동시에 게시된 3칸의 (타입·검사관·발주처 성향) 조합이 중복되지 않게 생성.
   같은 타입이 2칸을 넘지 않음. 첫 화면 지명 카드(house/lenient)는 종전대로 유지.
3. 빈 슬롯을 카드로 표시: "Next site — $60,000" 형태로 현장 영역에 항상 자리 차지.
   구매 가능하면 활성, 아니면 부족액 표시. 슬롯 3개까지 자리를 보여줘 성장 여지가 보이게.
4. 사운드 6종을 실제로 들어보고 어울리는지 확인할 수 없으므로 그대로 두되, 볼륨만 낮게(0.4) 고정.
5. 반영 후 커밋. 첫 화면 스크린샷 1장(게시판 3칸이 서로 다르고 입찰 가능한 상태) 보고 후 정지.
