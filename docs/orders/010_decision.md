# 010 판정 (광희님, 2026-10-12)

010 판정 (1~6 + 추가 7·8). 끝나면 /preview/ 재배포, 주소 한 줄과 4장면 스크린샷 보고 후 정지. 본편(루트) 전환은 광희님 승인 후.

1. 크레인: 높이 = 계획 층수 꼭대기 + 1.5층 높이(마스트 칸수 계산). 건물 오른쪽에 바짝 붙임(간격 = 건물 폭의 0.15). 카메라는 건물+크레인 머리를 함께 프레임. 1180·390 × 주택·8층 4장면에서 크레인 머리 전체가 보이는지, 건물이 화면 세로 몇 %인지 측정 보고.
2. 벡터 크레인 변경 승인.
3. 크기: 가설사무소 높이 = 작업자 키의 1.5배. 작업자 걷는 폭·대피 거리·검사관 이동 거리를 새 작업자 크기 비율로 조정. theme 토큰으로.
4. 환호(준공)·앉기(자금 정체) 포즈일 때는 이동 정지. 걷기·달리기·짐 나르기만 이동.
5. 펀치 처리는 짐 나르기 포즈 유지.
6. 카메라 상단 여백 = 런타임 HUD getBoundingClientRect().bottom + 8px. 리사이즈·회전 시 재계산. 8층 지붕이 HUD에 닿지 않는지 측정.
7. 건물 폭을 타입별 베이(기둥 사이 칸) 수로: 층 타일에서 기둥 위치를 찾아 베이 단위로 잘라 쓴다. house 2베이, lowrise 4베이, midrise 타일 전체. 기초·지붕도 같은 폭으로 잘라 맞춤(지붕 난간·끝단은 양 끝 캡을 살려서). 잘린 단면이 기둥 중심에서 끝나도록. 지금 미리보기에서 단독주택이 화면 가로를 꽉 채운 납작한 건물(주차빌딩처럼)로 보이는 문제 해결이 목적.
8. 기초 두께를 층 높이의 약 0.4배로 축소(지금은 층과 비슷해 건물이 더 납작해 보임).
