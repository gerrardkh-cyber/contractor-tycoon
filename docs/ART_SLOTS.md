# ART_SLOTS — 이미지 슬롯

발주서 009 §2·§3. 장면 가운데 **12조각**이 그림이 될 수 있다. 나머지는 벡터로 그린다.

- **원본 정의**: `tools/art-slots.json` — 가져오기 스크립트가 따르는 명세.
  게임이 아는 목록은 `src/ui/art.ts`, 실제로 들어온 그림 목록은 `src/ui/art-files.ts`(스크립트가 생성).
  셋이 어긋나면 `tests/ui-tokens.test.ts` 가 실패한다.
- **폴백**: `src/ui/art-files.ts` 에 없는 조각은 **지금처럼 벡터로 그린다.** 층 5상태는 다섯 장이
  모두 있어야 그림으로 바뀐다(한 층만 그림이고 나머지가 벡터면 쌓았을 때 섞이므로).
- **가져오기**: 저장소 루트에서 `python3 -I tools/import-art.py`.
  `art-raw/*.png` → 마젠타(`#FF00FF`) 키잉·디스필 → 시트 자르기 → 정규화·이음새 검사 →
  `public/art/<조각>.webp` + `src/ui/art-files.ts` + `art-raw/contact-sheet.png` + `art-raw/import-report.txt`.
- **용량 목표**: 전체 **3MB 이하**(`budgetBytes`).

## 원본 시트 → 조각

| 원본 시트 (`art-raw/`) | 자르기 | 조각 | 목표 폭(px) | 이음새 검사 |
|---|---|---|---|---|
| `floors.png` | 가로 5등분 | `floor-grid` · `floor-framing` · `floor-framed` · `floor-services` · `floor-complete` | 480 | **쌓기** — 아래 층 윗변과 위 층 아랫변의 벽 위치·색 |
| `foundation-roof.png` | 가로 2등분 | `foundation` · `roof` | 480 | — |
| `crane.png` | 가로 2등분 | `crane-tower` · `crane-jib` | 256 · 960 | — |
| `skyline-far.png` | 한 장 | `skyline-far` | 1920 | **가로 타일** — 좌우 끝 열 |
| `skyline-near.png` | 한 장 | `skyline-near` | 1920 | **가로 타일** — 좌우 끝 열 |
| `ground.png` | 한 장 | `ground` | 1920 | **가로 타일** — 좌우 끝 열. 흙의 윗선(지면선)을 찾아 기록 |

- **자르기**: "등분"은 기준일 뿐이다. 실제로는 그림 사이의 **빈(투명) 열**을 찾아 자르고,
  등분선이 그림을 관통하면 경고를 남긴 뒤 가장 가까운 빈 열로 옮긴다.
- **목표 폭**: 원본이 목표보다 작으면 **키우지 않고** 원본 폭을 유지하며 경고한다.
- 층 5조각은 **같은 폭·같은 높이**로 맞춘다. 모양이 5% 넘게 다르면 경고.

## 층 상태와 그림

| 게임 안의 층 상태 | 그림 |
|---|---|
| 미착공 (`waiting`) | `floor-grid` |
| 골조 중 (`structure`) | `floor-framing` |
| 골조 검사 대기 (`structureGate`) | `floor-framed` |
| 설비 중 (`services`) | `floor-services` |
| 설비 검사 대기 (`servicesGate`) | `floor-services` |
| 완료 (`done`) | `floor-complete` |

층 높이는 **그림의 비율을 그대로** 쓴다(건물 폭 × 그림 높이/폭). 그림을 숫자에 맞춰 찌그러뜨리지 않는다.

## 배치 규칙

| 조각 | 놓이는 곳 |
|---|---|
| `foundation` | 윗변이 기초 윗면에 맞는다. 기초 발은 지면 아래로 내려간다 |
| 층 5조각 | 기초 위로 같은 타일을 쌓는다 |
| `roof` | 아랫변이 최상층 윗면에 맞는다 |
| `crane-tower` | 지면에서 지브 높이까지, 마스트 자리에 선다 |
| `crane-jib` | 마스트 꼭대기에서 회전한다(기존 슬루 애니메이션 그대로) |
| `skyline-far` · `skyline-near` | 아래 끝이 지면선. 가로로 반복 |
| `ground` | **그림 속 흙의 윗선**이 장면의 지면선에 맞는다. 가로로 반복 |

## 이미지 슬롯 아님

아래는 **벡터로만 그린다.** 그림을 받지 않는다.

| 레이어 | 이유 |
|---|---|
| `sky` | 시간대(아침·낮·저녁·밤)마다 색이 바뀐다. 그라데이션 토큰으로 처리 |
| `rain` | 화면 전체를 덮는 애니메이션 |
| `workers` | 걷기·오르기·대피·앉기·환호 — 상태가 많고 움직인다 |
| `truck` | 진입·정차·후진 애니메이션 |
| `inspector` | 걸어 들어와 판정 말풍선을 띄우고 나간다 |
| `fence` | 빈 부지의 가림막. 부지 폭에 맞춰 그린다 |

## 그림을 쓸 때 잃는 것 (알려진 차이)

- **크레인 후크 상승**: 지브 그림이 자기 후크를 갖고 있어, 그림을 쓰면 그려진 후크(층 높이로
  오르내리던 것)를 숨긴다. 후크가 층을 따라 움직이는 연출은 그림 모드에서 사라진다.
- **밤 창문 불빛**: 그림 속 창문 위치를 알 수 없으므로, 완료 층 전체에 따뜻한 빛을 얇게 덮는다.
