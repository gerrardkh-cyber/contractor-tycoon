# ART_SLOTS — 이미지 슬롯

발주서 009 §2·§3, 010. 장면 가운데 **24조각**이 그림이 될 수 있다. 나머지는 벡터로 그린다.

- **원본 정의**: `tools/art-slots.json` — 가져오기 스크립트가 따르는 명세.
  게임이 아는 목록은 `src/ui/art.ts`, 실제로 들어온 그림 목록은 `src/ui/art-files.ts`(스크립트가 생성).
  셋이 어긋나면 `tests/ui-tokens.test.ts` 가 실패한다.
- **스위치**: `theme.artEnabled` 가 `false` 면 그림이 있어도 전부 벡터로 그린다(009 판정 A).
- **폴백**: `src/ui/art-files.ts` 에 없는 조각은 **벡터로 그린다.** 묶음은 전부 있어야 그림으로 바뀐다 —
  층 5상태, 크레인 3조각(머리·마스트·지브), 작업자 6포즈, 검사관 3포즈. 하나라도 빠지면 그 묶음은 벡터.
- **가져오기**: 저장소 루트에서 `python3 -I tools/import-art.py`.
  `art-raw/*.png` → 마젠타(`#FF00FF`) 키잉·디스필 → 시트 자르기 → 정규화·이음새 검사 →
  `public/art/<조각>.webp` + `src/ui/art-files.ts` + `art-raw/contact-sheet.png` + `art-raw/import-report.txt`.
- **용량 목표**: 전체 **3MB 이하**(`budgetBytes`). 010 기준 0.36MB.

- **자르기**: "등분"은 기준일 뿐이다. 실제로는 그림 사이의 **빈(투명) 열**을 찾아 자르고,
  등분선이 그림을 관통하면 경고를 남긴 뒤 가장 가까운 빈 열로 옮긴다. 두 그림이 겹친 구간은
  모양(연결 영역) 단위로 나눈다.
- **목표 폭**: 원본이 목표보다 작으면 **키우지 않고** 원본 폭을 유지하며 경고한다.
- 층 5조각은 **같은 폭·같은 높이**로 맞춘다. 모양이 5% 넘게 다르면 경고.
- 포즈 묶음(작업자·검사관)은 **한 캔버스 크기**로 맞추고 발끝을 아래에 붙인다 — 포즈를 바꿔도
  사람 크기가 변하지 않는다.

### 크레인 자르기 (010 §2)

- `crane-tower` 그림을 **머리**(운전석·꼭대기)와 **마스트 한 칸**(반복 구간)으로 자른다.
  머리 끝은 타워 폭이 마스트 폭으로 줄어드는 지점, 마스트 한 칸은 격자 무늬의 반복 주기
  (마스트를 자기 자신과 맞춰 본 주기)다. 머리 그림 속 마스트 중심을 `pivotX` 로 기록한다.
- `crane-jib` 은 트롤리 아래 매달린 **후크·와이어를 지운다**(긴 팔 쪽만, 짧은 팔의 평형추는 남김).
  지운 자리(후크가 매달렸던 가로 위치·와이어 시작 높이)를 `hookX`·`hookY` 로, 회전축과
  지브 보 높이를 `pivotX`·`beamY` 로 기록한다.

### 기둥과 베이 (010 판정 7, 011 A1)

- 스크립트가 층 5조각 **모두에 공통인 기둥**(층 높이의 20~80% 구간에서 90% 이상 단단한, 폭 4% 이하의 세로 띠)을
  찾아 중심 위치를 `columns`(폭 대비 비율)로 기록한다. 010 결과: **기둥 4개(4.5 · 159 · 320 · 474.5px) → 3베이.**
- 게임은 타입별 베이 수(`theme.svg.baysByType`: **주택·보수 1, 저층 2, 그 외(중층) 타일 전체**)만큼 타일을
  **기둥 중심에서** 잘라 이어 붙인다. 타일보다 적으면 **양 끝 베이**를 가져와(양쪽 끝 기둥·마감 유지) 가운데에서 잇는다.
  1베이는 첫 베이에 마지막 기둥의 바깥 절반(오른쪽 끝 마감)을 붙인다. **같은 베이를 두 번 쓰지 않는다**(011 A1) —
  타일보다 많이 요구하면 타일 전체.
- 기초·지붕도 같은 폭으로 자른다. 전체 그림 기준 배율 그대로, 폭의 왼쪽 절반은 그림 왼쪽 끝에서, 오른쪽 절반은
  오른쪽 끝에서 가져와 **양 끝 캡(난간 끝단·기초 발)**을 살린다.
- 층 높이는 타입과 관계없이 같다(타일 배율 고정). 베이 수만 건물 폭을 바꾼다.

### 창문 마스크 (010 §4)

- `floor-glow` 는 `floor-complete` 에서 **유리(파란 픽셀)** 만 골라 만든 그림이다.
  기준: 파랑이 빨강보다 25 이상, 초록 이상, 110 초과. 유리의 명암(창살·반사)을 살려 따뜻한 색으로 칠한다.
- 감지 결과는 가져오기 보고서에 `windows: N pane(s), M px of glass` 로 남는다. 010 결과: **3개 창 무리, 10,322px**.
  찾지 못하면 경고하고, 게임은 완료 층 전체를 얇게 덮는 방식으로 돌아간다.

## 층 상태와 그림

| 게임 안의 층 상태 | 그림 |
|---|---|
| 미착공 (`waiting`) | `floor-grid` |
| 골조 중 (`structure`) | `floor-framing` |
| 골조 검사 대기 (`structureGate`) | `floor-framed` |
| 설비 중 (`services`) | `floor-services` |
| 설비 검사 대기 (`servicesGate`) | `floor-services` |
| 완료 (`done`) | `floor-complete` (밤에는 위에 `floor-glow`) |

층 높이는 **그림의 비율을 그대로** 쓴다(건물 폭 × 그림 높이/폭). 그림을 숫자에 맞춰 찌그러뜨리지 않는다.

## 배치 규칙

| 조각 | 놓이는 곳 |
|---|---|
| `foundation` | 윗변이 기초 윗면에 맞는다. 기초는 지면 위로 **층 높이의 0.4배**(`foundationFloorShare`), 나머지는 지면 아래 |
| 층 5조각 | 기초 위로 같은 타일을 쌓는다. 타입별 베이 수만큼 잘라 잇는다 |
| `floor-glow` | 완료 층 위에 겹친다. **밤에만** 보인다 |
| `roof` | 아랫변이 최상층 윗면에 맞는다 |
| `crane-mast` | 지면에서부터 같은 칸을 쌓는다. **크레인이 건물과 함께 오른다**(011 A3): 지브 높이 = **지금 골조 중이거나 끝난 최상층 윗면 + 1.5층**(`craneClearanceFloors`)을 넘는 최소 칸 수. 층이 오를 때마다 새 칸이 0.6초에 걸쳐 끼워지며 머리가 올라가고(`craneClimbMs`), 준공 후 0.8초에 걸쳐 땅속으로 내려가 사라진다(`craneDownMs`). 마스트는 건물 오른쪽에 **건물 폭의 0.15** 간격(`craneGapShare`). **주택·보수 공사는 타워크레인이 없다**(`cranelessTypes`) |
| `crane-head` | 마스트 맨 위 칸에 얹는다(`pivotX` 가 마스트 중심) |
| `crane-jib` | 보 높이(`beamY`)가 마스트 꼭대기에 오도록, 회전축(`pivotX`)을 마스트에 맞춰 좌우 반전해 건물 쪽으로 뻗는다. 기존 슬루 애니메이션 그대로 |
| 후크·와이어 | **벡터.** 지브의 `hookX`·`hookY` 에서 내려와, 골조 중인 층 높이까지 길어진다(일이 없으면 마스트 중간쯤에서 쉰다) |
| `skyline-far` · `skyline-near` | 아래 끝이 지면선. 가로로 반복 |
| `ground` | **그림 속 흙의 윗선**이 장면의 지면선에 맞는다. 가로로 반복 |
| 작업자·검사관 | 화면 높이 **층 높이의 40%**(`figureFloorShare`). 발끝이 지면선(또는 층 바닥). 가설사무소 높이·걷는 폭·대피 거리·작업자 간격·검사관이 서는 곳과 걸어오는 거리는 모두 **작업자 키 단위**(`hutHeightPeople` 1.5 등) |
| `truck` | 높이 **층 높이의 85%**(`truckFloorShare`). 오른쪽을 보고 들어와 서고, 그대로 후진해 나간다 |

## 내 회사의 스카이라인 (011 §4~6)

- 준공한 건물은 장면 뒤쪽 레이어(`skyline-near` 앞, 현장 뒤)에 **카메라 배율의 0.6배**(`landmarkScale`)로 남는다.
  단, 가장 높은 건물이 HUD 아래 공간의 80%(`landmarkRoomShare`)를 넘지 않도록 전체를 함께 줄인다.
- 그림은 현장 건물과 같은 조각(층·기초·지붕, 밤 창문 마스크 포함)으로, **완료 상태 · 크레인·깃발 없음**.
- 배치: 오래된 것부터 **행 왼쪽부터, 진행 중인 현장과 이미 놓인 건물을 피해** 빈자리에. 빈자리가 없으면 가장 덜 겹치는
  자리. 현장 행과 함께 스크롤된다. **최대 12채**(`landmarkMax`), 넘으면 가장 오래된 것부터 빠진다.
- 준공 순간: 크레인이 내려간 뒤(0.8초) 현장 건물이 **0.8초에 걸쳐 줄어들며 뒤쪽 자리로 이동**(`landmarkMoveMs`), 부지는 펜스 공터로.

## 포즈와 상태

그림은 모두 **오른쪽을 본다.** 왼쪽으로 갈 때는 좌우 반전한다.

| 상태 | 작업자 포즈 |
|---|---|
| 지상에서 오가기 | `worker-walk-a` ↔ `worker-walk-b` 교대. 왕복의 돌아오는 길에서 반전 |
| 골조 층 위(2명) | `worker-carry`, 오가며 |
| 펀치 처리 중(층 위) | `worker-carry`, 오가며 (011 A5) |
| 자금 부족 정체 | `worker-sit`, **그 자리에 멈춤** |
| 비 대피(왼쪽 가설사무소로) | `worker-run`, 왼쪽을 봄 |
| 준공 | `worker-cheer`, **그 자리에 멈춤** |

걷기·달리기·짐 나르기만 움직이고, 환호·앉기는 멈춘다(010 판정 4).

| 검사관 방문 구간 | 포즈 |
|---|---|
| 걸어 들어옴(오른쪽→왼쪽) | `inspector-walk`, 반전 |
| 머무는 전반 | `inspector-check` |
| 머무는 후반 — 합격 | `inspector-thumb` |
| 머무는 후반 — 불합격 | `inspector-check` 유지 |
| 걸어 나감 | `inspector-walk` |

## 이미지 슬롯 아님

아래는 **벡터로만 그린다.** 그림을 받지 않는다.

| 레이어 | 이유 |
|---|---|
| `sky` | 시간대(아침·낮·저녁·밤)마다 색이 바뀐다. 그라데이션 토큰으로 처리 |
| `rain` | 화면 전체를 덮는 애니메이션 |
| `fence` | 빈 부지의 가림막. 부지 폭에 맞춰 그린다 |

가설사무소(비 대피처)·후크와 와이어·판정 말풍선도 벡터다.
