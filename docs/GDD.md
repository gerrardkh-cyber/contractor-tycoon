## 1. 한 줄 정의
플레이어는 **시공사(General Contractor)** 다. 발주처(NPC)의 공사를 수주하고, 협력업체를 굴려 공정을 돌리고, 검사를 통과시키고, 기성을 받아 회사를 키운다. **방치형(idle)** 진행.

## 2. 플랫폼 / 제출 요건
- 영어권 웹게임 포털, **CrazyGames 우선**.
- 게임 내 모든 텍스트 **영어**.
- 오프라인 실행 가능, 외부 CDN 의존 0.
- 초기 로딩 10초 미만, 빌드 20MB 미만.

## 3. 코어 루프

```
RFQ (입찰 공고)
  → 견적 3단계 선택 (Low / Fair / High)
  → 낙찰 or 유찰
  → 시공 (공정 파이프라인)
  → 검사 게이트 (합격 / 불합격→재작업)
  → 기성 (progress payment)
  → 준공 (CO, Certificate of Occupancy)
```

### 3.1 RFQ
발주처 NPC가 공사 건을 공고한다. 플레이어는 목록에서 입찰 대상을 고른다.

### 3.2 견적 3단계
플레이어는 **Low / Fair / High** 세 단계 중 하나를 고른다.
각 단계는 선택 화면에 **낙찰 확률**과 **마진**을 함께 표시한다.

| 단계 | 낙찰 확률 | 마진 | 검사 불합격 확률 기여 |
|---|---|---|---|
| Low | 높음 | 낮음 | 증가 |
| Fair | 중간 | 중간 | 중립 |
| High | 낮음 | 높음 | 감소 |

수치는 전부 `BALANCE.md` TBD.

### 3.3 입찰 실패 구제
**입찰 3연속 실패 시, 4번째는 지명 입찰(negotiated / sole-source)** 로 제공한다.
→ 초반 플레이어가 확률에 막혀 진행 정지하는 것을 막는 안전장치.
- 카운터 리셋 조건: TBD
- 지명 입찰의 마진 패널티 여부: TBD

### 3.4 기성
공정 진척에 따라 기성이 분할 지급된다.
- 지급 시점(검사 게이트 기준 / 진척률 기준): TBD
- **기성 감액 이벤트** 존재 (아래 7.3).

### 3.5 준공 (CO)
Final 검사 통과 시 CO 발급, 프로젝트 종료, 잔금 정산, 발주처 신뢰도 갱신.

## 4. 프로젝트 타입 — 템플릿 구조

프로젝트 타입은 **데이터 템플릿**으로 정의한다. 코드에 타입별 분기를 박지 않는다.

| 버전 | 타입 | 상태 |
|---|---|---|
| v1 | **Building** (빌딩) | 구현 대상 |
| v2 | **Plant** (플랜트) | 슬롯만 확보 |
| v3 | **Fab** (팹) | 슬롯만 확보 |

v2 / v3 는 **슬롯만 비워둔다.** 이번 버전에서 내용을 채우지 않는다.

### 4.1 Building 공정 — 층 단위 반복 파이프라인
층(floor) 단위로 공정이 **겹쳐서(pipelined)** 흐른다.

```
골조 n층 완료 → 설비(MEP) n층 진입,  동시에 골조 n+1층 착수
```

즉 골조가 앞서 나가고 설비가 뒤따라 오는 **2단 파이프라인**. 층 수만큼 반복.

건물 마지막에:
```
방수(Weatherproofing) → 소방(Fire) → 최종 검사(Final) → CO
```

- 파이프라인 단(stage) 수를 3단 이상으로 늘릴지: TBD
- 층별 소요 시간 / 비용: `BALANCE.md` TBD

## 5. 검사 게이트 (Inspection Gates)

| 게이트 | 단위 | 시점 |
|---|---|---|
| Foundation | 프로젝트 1회 | 기초 완료 |
| Structural | **층별** | 해당 층 골조 완료 |
| Rough-in MEP | **층별** | 해당 층 설비 완료 |
| Weatherproofing | 프로젝트 1회 | 방수 완료 |
| Fire Marshal | 프로젝트 1회 | 소방 완료 |
| Final | 프로젝트 1회 | 전체 완료 |
| → CO | — | Final 통과 시 |

### 5.1 불합격 처리
불합격 시:
1. **재작업(rework)** — 해당 구간 공정 되돌림 + 추가 시간·비용
2. **발주처 신뢰도 하락**

### 5.2 불합격 확률 공식
```
불합격 확률 = f( 협력업체 레벨, 견적 마진, 활성 이벤트 )
```
- 협력업체 레벨 높을수록 ↓
- 견적 마진 낮을수록(Low 견적) ↑
- 이벤트에 따라 가감
- 정확한 함수 형태와 계수: `BALANCE.md` TBD

### 7.1 동시 현장 수
**v1 최대 3개.** 확장 조건: TBD.

### 7.2 프레스티지
**회사 매각 후 재창업.** 매각 시 자산을 환산해 영구 보너스를 얻고 새 회사로 시작.
- 환산 공식 / 영구 보너스 종류: TBD

### 7.3 발주처 담당관 (Client Officer)
각 발주처에는 담당관이 있고, **성향이 입찰 화면에 표시된다.**

| 성향 | 영문 | 영향 |
|---|---|---|
| 가격 중시 | Price-driven | Low 견적 낙찰 확률 ↑ |
| 실적 중시 | Record-driven | 신뢰도 가중치 ↑ |
| 기한 중시 | Schedule-driven | 공기 지연 페널티 ↑ |
| 깐깐함 | Strict | 검사 불합격 확률 ↑ |

**기성 감액 이벤트**: 담당관이 기성 청구액을 깎는 이벤트. 조건·빈도·감액률 TBD.
